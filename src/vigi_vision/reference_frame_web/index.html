요청한 프레임 후보 생성

하나의 녹화 시각 주변에서 정해진 위치를 검토합니다. 후보 시각은 요청한 위치이며 실제 촬영 시각과 정확히 일치하지 않을 수 있습니다.

요청 정보

첫 검토 단계에서는 기본 오프셋을 사용합니다.

채널 불러오는 중…

초 단위까지 유지됩니다. 날짜 선택기는 브라우저 설정을 따르며, 적용된 요약은 24시간 형식으로 표시됩니다.

입력한 현지 시각에 사용할 IANA 시간대를 선택하세요.

적용된 기준 시각

후보를 생성하는 중입니다. 몇 분 정도 걸릴 수 있습니다.

후보 결과

결과는 서버가 제공한 요청 순서로 표시됩니다.

후보를 생성할 준비가 되었습니다.

성공한 후보 하나 선택

후보 선택은 임시이며 이 브라우저 탭에서만 유지됩니다.

    선택한 후보

    선택한 프레임에서 정보용 관심 영역(ROI)을 하나 그립니다.

    선택한 후보가 없습니다.

    ROI 작업 영역

    먼저 후보를 선택한 다음 마우스, 터치 또는 펜으로 이미지 위를 드래그하세요. 이미지 밖에서는 페이지를 계속 스크롤할 수 있습니다.

    드래그하여 대상을 선택하세요. 상자를 드래그해 이동하거나 핸들로 크기를 조정할 수 있습니다. 상자에 초점을 맞추면 화살표 키로 이동합니다. Shift+화살표는 원본 픽셀 10만큼 이동하고, Alt+화살표는 크기를 조정합니다(Alt+Shift는 10만큼 조정). Delete 또는 Backspace는 ROI를 초기화하고, Escape는 진행 중인 편집을 취소합니다.

    먼저 후보를 선택하세요.

    사용 가능한 후보를 선택하면 ROI 자동 제안을 사용할 수 있습니다.
